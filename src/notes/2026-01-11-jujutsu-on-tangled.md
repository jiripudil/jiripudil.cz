This post demonstrates how [Tangled](https://tangled.org) uses Jujutsu's change-ids to streamline the code review process in an evolving merge request – something I've been pondering for some time myself.

The mixture of discussions, new commits, amended commits, and rebases, makes code review messy in traditional tools such as Gitlab, and this seems to make it really streamlined.
